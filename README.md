# همیار ساختمان

سامانه فارسی ثبت و پیگیری خدمات فنی ساختمان در گرگان.

## اجزای برنامه
- `index.html`: رابط کاربری، پنل مشتری، متخصص و مدیر
- `manifest.webmanifest` و `sw.js`: نصب‌پذیری و پوسته آفلاین PWA
- `privacy.html`: پیش‌نویس سیاست حریم خصوصی
- `PLAY_GUIDE.md`: راهنمای بسته‌بندی و انتشار در Google Play

## اتصال Supabase
پروژه فعلی در فایل `index.html` با URL و کلید عمومی (publishable) متصل شده است. کلید عمومی برای استفاده در مرورگر طراحی شده است؛ هرگز کلید `service_role` یا کلید محرمانه را در فایل‌های GitHub قرار ندهید.

### ورود پیامکی
ورود و ثبت‌نام برنامه با شماره موبایل و کد یک‌بارمصرف SMS انجام می‌شود. پیش از تست:
1. در Supabase به **Authentication → Providers → Phone** بروید و Phone provider را فعال کنید.
2. یک ارائه‌دهنده پیامک پشتیبانی‌شده را تنظیم و اعتبارنامه آن را وارد کنید.
3. در **Authentication → URL Configuration** دامنه GitHub Pages را به Site URL و Redirect URLs اضافه کنید.
4. ارسال OTP را با شماره‌ای که امکان دریافت پیامک آن را دارید آزمایش کنید.

فعال‌سازی پیامک و ارائه‌دهنده آن باید در تنظیمات داشبورد انجام شود؛ کد برنامه به‌تنهایی امکان ارسال SMS را ایجاد نمی‌کند.

## نقش‌ها و جریان کار
- مشتری: ورود پیامکی، انتخاب نوع خدمت و محله، ثبت درخواست، پیگیری وضعیت و امتیازدهی.
- متخصص: ثبت تخصص و محله‌های فعالیت؛ پس از تأیید مدیر و داشتن اشتراک متخصص، مشاهده و به‌روزرسانی کارهای ارجاع‌شده.
- مدیر: تأیید متخصصان، تأیید اشتراک‌ها و ارجاع درخواست‌های بدون متخصص.
- اشتراک مشتری و متخصص جداگانه تعریف شده‌اند.

## نکته پیش از انتشار عمومی
سیاست حریم خصوصی موجود پیش‌نویس است. اطلاعات تماس پشتیبانی، شرایط مالی و فرایندهای حقوقی باید پیش از انتشار عمومی بازبینی و تکمیل شوند.
